# GestureControlledCamera

This Project was created as a showcase of the utility of computer vision as a system controller. Utilizing Google Mediapipe Solutions gesture recognizer, the machine vision model reads both the position of the user's hand as well as a set number of gestures in order to control a custom physical webcam mount using a Raspberry Pi microcomputer. The system can reposition the camera to follow the user's had, as well as take a photo, start and stop recording a video, and shut itself off while returning to a centered position.
